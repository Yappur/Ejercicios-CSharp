Variables
Una variable es un espacio en memoria donde guardás un valor. En C# tenés que declarar el tipo de dato que va a contener:

edad = 25;
string nombre = "Juan";
double precio = 19.99;
bool activo = true;

La estructura es siempre tipo nombreVariable = valor;. C# es un lenguaje fuertemente tipado, así que una vez que declarás una variable como int, no podés guardarle un texto después. También existe var, que deja que el compilador infiera el tipo automáticamente:

ciudad = "Buenos Aires"; // el compilador sabe que es string
